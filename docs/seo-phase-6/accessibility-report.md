# Accessibility Report

Research date: 2026-07-21

## Checks Applied

- One H1 per page.
- Sequential H2/H3 content sections.
- Descriptive link text in related-content panels.
- Keyboard-accessible native links and buttons.
- Visible browser focus remains available; no custom focus removal was added.
- Mobile layout uses the existing responsive SEO template.
- Tables in documentation are not shipped as public UI.
- No intrusive popups or interstitials were added.
- No new motion was added to static SEO pages.

## Corrections Made

- Landing-page public links were moved to extensionless canonical URLs.
- Static pages use descriptive anchors rather than repeated exact-match anchors.
- Sensitive safety pages use careful language and direct users toward support/official channels when appropriate.

## Deferred

- Full manual screen-reader testing was not performed.
- Homepage app accessibility remains outside the narrow static Wave 2 content scope except for the measured performance cleanup.
